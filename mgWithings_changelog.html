Changelog MG Withings

  • Aide : un bloc de code s'affiche tel quel, sans mise en forme accidentelle de son contenu.

v2.1.53 - 30/10/2026

  • Aide : un lien écrit dans du code reste du code.

v2.1.53 - 27/10/2026

  • Fil d'actualité : les alertes de cohérence des pesées portent désormais le niveau « info » comme les autres lignes.

v2.1.53 - 26/10/2026

  • Sauvegarde Jeedom : les anciennes versions de travail conservées par le plugin n'y sont plus incluses, la sauvegarde quotidienne est plus légère.

v2.1.53 - 23/10/2026

  • Nouvelle page « Présentation du plugin », en tête du sommaire de l'aide : ce que fait le plugin, en une page.

v2.1.53 - 19/10/2026

  • Les fichiers internes d'installation du plugin ne sont plus accessibles depuis le navigateur.
  • Les icônes du panneau et de l'onglet Equipement s'affichent de nouveau ; le panneau est réservé aux administrateurs, comme ses données.
  • Les boutons Documentation et Changelog de Jeedom ouvrent la documentation du plugin.

v2.1.52 - 16/10/2026

  • Les identifiants internes des commandes de mesure prennent des noms explicites (par exemple poids, masse_grasse).
  • Le journal ne signale plus à tort un lien Withings indisponible pour une balance, ni pour un compte pas encore lié.
  • Le panneau retrouve l'intitulé encadré au-dessus de chaque graphique.

v2.1.51 - 15/10/2026

  • Corrections mineures.

v2.1.49 - 14/10/2026

  • Le panneau du plugin apparaît d'office dans le menu Accueil dès l'installation ; il se masque en décochant « Afficher le panneau desktop » dans la configuration du plugin.

v2.1.47 - 12/10/2026

  • Coupure internet : si la commande mémo réglée dans MG Domo est supprimée ou n'est pas une info, plus d'erreur à chaque passage (une ligne par heure au journal de MG Domo) ; le plugin fonctionne comme sans coupure.
  • Le bouton « Documentation » de Jeedom ouvre la documentation en ligne (PDF) ; l'historique des versions est lui aussi consultable en ligne.
  • Icône au nouveau format du Market Jeedom ; description du plugin complétée.
  • Fiche du plugin : versions de Debian prises en charge et langue déclarées.

v2.1.43 - 10/10/2026

  • Jeedom 4.4 minimum requis, comme les autres plugins mgDomo ; plugin libéré : installable et mis à jour sur toutes les installations.
  • Import de la nuit fiabilisé : il renouvelle l'autorisation si besoin au lieu d'être sauté, sans conflit avec la synchronisation lancée au même moment ; la valeur affichée reste la dernière pesée.
  • Synchronisation allégée : seules les mesures des 7 derniers jours sont demandées (quelques Ko au lieu d'environ 500 Ko toutes les 30 minutes) ; les demandes inutiles de sommeil et d'activité sont retirées.
  • Journal plus calme : un incident qui se règle seul n'y laisse qu'une information ; avertissement seulement si Withings reste injoignable 3 heures ou refuse l'autorisation 3 fois.
  • Vos noms, unités et historisation de commandes sont respectés ; libellés accentués ; secret masqué dans la configuration ; panneau des graphiques corrigé ; la liaison Withings ne demande plus que l'accès aux mesures.

v2.1.36 - 09/10/2026

  • Description du plugin corrigée (liste des plugins et documentation) ; panneau mobile retiré (inutilisé) ; le panneau des graphiques reste.
  • Aide complétée : liaison Withings, panneau des graphiques (période, groupement, choix des graphes), onglet Commandes ; libellés de la configuration corrigés.
  • Licence clarifiée : GNU AGPL v3, auteur Michel Georgein.
  • Page du plugin : une erreur s'affiche désormais en message au lieu de bloquer la page ; le statut du mode push se met à jour après activation ou désactivation.
  • Fichiers de traduction retirés (ils ne traduisaient presque rien) : le plugin s'affiche en français dans toutes les langues, comme les autres plugins mg*.

v2.1.29 - 08/10/2026

  • Les encarts d'aide des pages du plugin sont sur fond clair, en texte sombre, avec des liens bien visibles : lisibles dans les deux thèmes (charte MG Domo 4.8).
