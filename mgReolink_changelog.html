  • Aide : un bloc de code s'affiche tel quel, sans mise en forme accidentelle de son contenu.

v2.1.52 - 30/10/2026

  • Aide : un lien écrit dans du code reste du code.

v2.1.52 - 26/10/2026

  • Sauvegarde Jeedom : les anciennes versions de travail conservées par le plugin n'y sont plus incluses, la sauvegarde quotidienne est plus légère.

v2.1.52 - 23/10/2026

  • Nouvelle page « Présentation du plugin », en tête du sommaire de l'aide : ce que fait le plugin, en une page.

v2.1.52 - 19/10/2026

  • Les boutons Documentation et Changelog de Jeedom ouvrent la documentation du plugin.

v2.1.51 - 18/10/2026

  • Une caméra qui refuse ses identifiants n'est plus redémarrée toutes les 30 minutes : le journal signale le refus, corrigez l'identifiant ou le mot de passe.
  • Aide et documentation : seules les relectures d'état sont groupées par 4 ; une action part seule.

v2.1.50 - 17/10/2026

  • À installer avec MG Domo du même jour.

v2.1.48 - 14/10/2026

  • Historique : marque écrite « mgDomo ».

v2.1.47 - 12/10/2026

  • Le bouton « Documentation » de Jeedom ouvre la documentation en ligne (PDF) ; l'historique des versions est lui aussi consultable en ligne.
  • Icône au nouveau format du Market Jeedom ; description du plugin complétée.

v2.1.45 - 10/10/2026

  • Compatible avec Jeedom 4.4 (4.5 n'est plus exigé).
  • Plugin libéré : installable et mis à jour sur toutes les installations.
  • L'état du microphone est de nouveau relu sur la caméra ; « Tester » détecte un mot de passe faux ; les actions sont plus rapides.
  • Une caméra qui ne répond pas une fois ne crée plus de message d'erreur ; seule une panne confirmée est signalée. Toute caméra est contrôlée toutes les 5 minutes.
  • Mode jeton fiable après un redémarrage de caméra ; « Informations » enregistre la caméra même sans image du modèle.

v2.1.39 - 09/10/2026

  • Description du plugin corrigée (liste des plugins et documentation).
  • Aide complétée : identité de l'équipement, aperçu de la caméra, colonnes de l'onglet Commandes.
  • Licence clarifiée : GNU AGPL v3, auteur Michel Georgein.

v2.1.36 - 08/10/2026

  • Les encarts d'aide des pages du plugin sont sur fond clair, en texte sombre, avec des liens bien visibles : lisibles dans les deux thèmes (charte MG Domo 4.8).

v2.1.35 - 07/10/2026

  • Textes de la fiche, de la configuration, des messages et de la documentation relus : vouvoiement, accents, aides complétées.
  • Configuration : la méthode d'authentification affichée est désormais celle réellement utilisée (identifiant et mot de passe par défaut).
  • Documentation corrigée : HTTPS est le type de connexion par défaut ; ajout de l'auto-redémarrage et du comportement en cas de caméra injoignable.

v2.1.34 - 03/10/2026

  • Le plugin déclare son matériel « Caméras Reolink » : il figure dans l'onglet Plugins de MG Domo, tableau « Plugins liés à un matériel », avec la case « présent ».

v2.1.33 - 22/09/2026

  • Fiche équipement : les boutons Tester, Informations et Commandes passent dans le titre du groupe « Informations », aux couleurs communes. Aucun changement de fonctionnement.

v2.1.32 - 21/09/2026

  • Fiche d'une caméra, page de configuration, page d'accueil et onglet Commandes remis en page selon la charte mgDomo, avec aides « ? » sur chaque champ.
  • « Catégorie » propose les huit catégories de Jeedom ; « Options » devient « Etat du widget » et l'accès à la caméra s'appelle « Connexion ».
  • Le bouton de suppression d'une commande disparaît, les commandes étant créées par le plugin.

v2.1.28 - 19/09/2026

  • Journal : un échec de lecture isolé d'une caméra n'est plus un avertissement ; l'avertissement est réservé à la panne confirmée, au deuxième échec.

v2.1.27 - 12/09/2026

  • Journal : une caméra injoignable n'écrit plus un avertissement toutes les cinq minutes, seulement aux deux premiers échecs ; son retour reste signalé.

v2.1.26 - 11/09/2026

  • Le message « caméra injoignable » n'est plus envoyé sur un échec isolé, mais au deuxième échec consécutif : une coupure brève ne déclenche plus d'alerte.
  • La caméra reste marquée indisponible dès le premier échec, et les actions des scénarios sont suspendues comme avant.
  • Journal allégé : seuls l'essentiel et les vraies suppressions de commandes restent visibles en niveau Info.

v2.1.23 - 07/09/2026

  • Sécurité : les fichiers d'archives du plugin ne sont plus accessibles par le serveur web.

v2.1.22 - 30/08/2026

  • Correction : en passant d'une caméra à l'autre, le champ « Port » ne garde plus la valeur de la caméra précédente, ce qui pouvait casser la connexion à la sauvegarde.

v2.1.21 - 29/08/2026

  • Nouvelle vignette « Community » : elle prépare une demande d'aide avec le rapport anonymisé du plugin et ouvre directement le sujet sur le forum Jeedom.
  • L'icône de demande d'aide passe en orange, avec une infobulle qui explique son rôle.

v2.1.17 - 28/08/2026

  • Si le socle MG Domo manque, le message d'installation indique la commande à exécuter pour compléter l'installation.

v2.1.16 - 21/08/2026

  • Le redémarrage automatique n'est plus tenté quand la caméra est absente du réseau : fin du message quotidien de redémarrage physique pour une caméra éteinte la nuit.
  • Il reste actif quand la caméra répond sur le réseau mais ne répond plus aux commandes.
  • Une caméra injoignable est toujours signalée une fois et ses actions restent suspendues jusqu'à son retour.

v2.1.15 - 19/08/2026

  • Une caméra figée qui répond encore sur le réseau est désormais détectée comme injoignable, avec alerte et suspension des actions.
  • Le redémarrage automatique passe par ONVIF, seul canal encore utilisable quand la caméra est figée.
  • Corrections : le plugin ne se croit plus connecté sans avoir contacté la caméra ; les cases à cocher affichent toujours l'état réel de la caméra consultée.

v2.1.14 - 04/07/2026

  • Une nouvelle caméra utilise HTTPS par défaut, comme le réglage d'usine Reolink.
  • Suppression d'un mécanisme de détection hérité qui ne produisait aucun effet.

v2.1.12 - 26/06/2026

  • Une caméra figée ne sature plus les journaux : elle est signalée une seule fois par un message Jeedom quand elle devient injoignable.
  • Les actions de scénario sur une caméra injoignable sont ignorées immédiatement, sans attente.
  • Nouvelle case « Auto-redemarrage » par caméra, désactivée par défaut, pour tenter de relancer une caméra figée.

v2.1.11 - 24/06/2026

  • Documentation illustrée complète : 8 chapitres et 6 figures (configuration, boutons, commandes, authentification, aperçu).

v2.1.6 - 21/06/2026

  • La documentation du plugin s'ouvre depuis les boutons d'aide de Jeedom.

v2.1.1 - 15/06/2026

  • Sécurité : la clé de la caméra n'apparaît plus dans la page ; l'aperçu passe par le serveur et demande une session administrateur.
  • Plus d'erreurs quand une caméra est injoignable, et journal moins bavard à l'enregistrement des équipements.
